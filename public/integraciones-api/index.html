Preguntas frecuentes

¿Qué sistemas se pueden integrar?

Casi cualquier sistema que tenga API, acceso a base de datos o archivos de intercambio. Si un sistema no tiene API, evaluamos otras alternativas en el diagnóstico.

¿Qué pasa si una integración falla?

Diseñamos las integraciones con registro de cada envío y avisos cuando algo no se procesa, para detectarlo y corregirlo a tiempo.

¿Pueden crear una API para que mis clientes se conecten?

Sí. Desarrollamos APIs con acceso controlado y documentación para que tus clientes o socios se integren.

¿Las integraciones necesitan un servidor?

Normalmente sí. Podemos usar tu infraestructura actual o montarla en la nube con AWS.
